Integrity

MANIFEST.json lists public source URLs, byte sizes and SHA-256 hashes. SHA256SUMS.txt covers every payload file plus the manifest, excluding itself to avoid a circular checksum. The checksum of the complete ZIP is published separately with the download. Save that checksum independently with the ZIP. A checksum detects differences from the referenced edition; it is not a digital signature, independent timestamp, or proof that factual claims are true.

Windows PowerShell: Get-FileHash .\OriginDossier-PublicArchive-2026-10-18-v3.zip -Algorithm SHA256. Linux: sha256sum OriginDossier-PublicArchive-2026-10-18-v3.zip. macOS: shasum -a 256 OriginDossier-PublicArchive-2026-10-18-v3.zip.
